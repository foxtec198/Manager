# Hubbix Manager
## Sistema de Gestão | Management system

O Manager é voltado para Lojas de Celulares, Notebooks e computadores, feito especialmente para gestão de Vendas, Caixa, Estoque, Ordens de Serviço e muito mais, com uma gama de serviços, com um UI grafica simples e facil de entender.

> Manager is designed for Cell Phone, Notebook and Computer Stores, specifically for managing Sales, Cash Register(POS), Inventory, Service Orders and much more, with a range of services and a simple, easy-to-understand graphical UI.

Abaixo algumas das funcionalidades do sitema, listadas de acordo com o genero, porém há muito mais pro trás do sistema de fato.
